📌 Overview

AI Hospital Management System is a Full Stack MERN Project developed for hospital administration.

The system allows hospitals to efficiently manage:

👨‍⚕ Doctors
🧑 Patients
📅 Appointments
📊 Analytics Dashboard
🤖 AI Symptom Checker
📄 PDF Reports
📈 Excel Reports

This project was built as a B.Tech Computer Science Mini Project.

Backend

npm install
npm run dev
